**Coding rule (王总 11-27):** A01xxxx = 外采原料 (purchased); A02xxxx = 在产品/装置存料 (WIP); A03xxxx = 自产产品 (own products, may also be another unit's feed). LPG is both bought (A010009) and self-produced (A030004).

**Product chains (derived):** 石脑油 → 轻油改质 → 氢气/工业氢, 燃料气, 液化气, 异戊烷, 苯, 甲苯, 二甲苯, 加氢石脑油, 硫磺. 苯 + 乙烯 + 催化干气 → 乙苯单元 → 乙苯 → 苯乙烯单元 → 苯乙烯 (+甲苯). 液化气 → 气分 → 丙烷, 丁烷, 正丁烷≥98% → 顺酐单元 → 顺酐. 工业氢 + 氮气 → 合成氨 → 液氨, 氨水. DIBP（邻苯二甲酸二异丁酯）+ 工业氢 → DIBE装置（加氢）→ DIBE（六氢邻苯二甲酸二异丁酯，A030023）. Codes confirmed from system 11-27: DIBP A010006, DIBE A030023. DIBE装置 runs only around 顺酐 start-up; idle in Nov 2026 (so no data missing); its H2 is 工业氢 from 轻油改质 (王总 11-27).
